# AI-Credit-Risk-Prediction-System
Machine Learning based Credit Risk Prediction and Banking Analytics System using Python, XGBoost, Power BI and Streamlit.
This project focuses on predicting loan default risk using Machine Learning techniques and banking datasets.

## Tech Stack
- Python
- Pandas
- Scikit-learn
- XGBoost
- Power BI
- Streamlit

## Features
- Credit Risk Prediction
- Exploratory Data Analysis
- Banking Analytics Dashboard
- Explainable AI
- Streamlit Deployment
